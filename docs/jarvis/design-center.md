# Design Center

Penpot зарегистрирован как будущий Docker on-demand provider Design Center с generic capabilities `design.project.open/list/export`. Он не заменяет Dashboard и не запускается автоматически вместе с JARVIS. В текущем compose установлен только проверенный n8n-профиль; поэтому Penpot честно остаётся `REGISTERED_DISABLED/NOT_INSTALLED`, а кнопки дизайна не выдают фиктивный успех.

Paperless-ngx аналогично является опциональным Document Archive и не заменяет существующий Document Router.
